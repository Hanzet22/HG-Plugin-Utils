# HG PG Global Themes for Aliucord

Six global color themes designed for Aliucord's Themer plugin. These JSON files recolor supported Discord/Aliucord UI resources, including major backgrounds, accent colors, selected-channel colors, input surfaces, and links. They are not limited to HG PG's own floating panel.

## Included themes

1. Deep Sea Blue
2. Garuda Indonesia
3. Light Emitting Orange
4. Gran Turismo Sport
5. Gran Turismo Old
6. CRT PS2

## Install

1. Install/enable the Themer plugin in Aliucord.
2. Download hg-pg-global-themes.zip from the latest Build HG PG GitHub Actions run.
3. Extract the six JSON files into Aliucord/themes/ (the themes directory under Aliucord's base folder).
4. Restart Aliucord, open User Settings → Plugins → Themer, and enable exactly one HG PG theme.
5. Keep Discord in Dark mode for the most consistent palette.

The plugin's own Animated Theme Garage remains responsible for its custom animated launcher/panel effects. The global theme JSONs recolor the supported app UI through Themer. They do not animate every individual Discord control; Themer's animated wallpaper feature is a separate option and may require a transparency mode that can affect readability/performance.

## Notes

- Themer's theme format and resource mappings can change between Aliucord versions.
- Some hard-coded or third-party UI elements may retain their original colors.
- Avoid enabling several global themes simultaneously because their color overrides can conflict.
- If a theme looks unreadable, disable it in Themer and restart Aliucord.
